MarkNest Privacy Policy

MarkNest 隐私政策

Effective: August 10, 2026生效日期：2026 年 8 月 10 日

MarkNest helps users view, filter, move, delete, import, export, and check Chrome bookmarks. The extension requires no account and contains no ads, behavioral analytics, or AI services.

MarkNest 用于帮助用户查看、筛选、移动、删除、导入、导出和检查 Chrome 收藏。扩展不要求账号，不包含广告、行为分析或 AI 服务。

Local processing

本地处理

Bookmark titles, URLs, folder paths, creation dates, Chrome-provided last-used dates, interface settings, undo snapshots, and imported bookmark HTML are processed locally on the device. They are not sent to the developer or third-party servers.

收藏标题、网址、文件夹路径、创建时间、Chrome 提供的最近使用时间、界面设置、撤销快照和导入的书签 HTML 均在设备本地处理，不会发送给开发者或第三方服务器。

Link checking

链接检查

Only when the user starts a link check and grants website access does MarkNest connect directly to bookmarked URLs to determine whether they respond. It records only the check status and does not read or save page content.

只有当用户主动运行链接检查并授权网站访问后，扩展才会直接访问相应收藏网址，以判断其是否可连接。扩展只记录检查状态，不读取或保存页面正文。

Sharing and sale

共享与出售

MarkNest does not sell, rent, or share user data and does not use data for advertising, profiling, credit decisions, or purposes unrelated to its core functionality.

MarkNest 不出售、出租或共享用户数据，也不将数据用于广告、画像、信用或与扩展核心用途无关的目的。

Storage and deletion

保存和删除

Settings, check results, and undo snapshots are stored in Chrome extension storage. Chrome removes this extension data when MarkNest is uninstalled.

设置、检查结果和撤销快照保存在 Chrome 扩展存储中。卸载扩展后，Chrome 会清除这些扩展数据。

Contact

联系

For privacy questions, open an issue in the MarkNest GitHub repository or use the support contact listed on the Chrome Web Store.

如有隐私问题，请在 MarkNest GitHub 仓库提交 Issue，或使用 Chrome 网上应用店中列出的支持联系方式。
