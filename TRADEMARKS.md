The source code in this repository is licensed under GPL-3.0. That license does not grant permission to use the MarkNest name, logo, extension icon, or other brand assets to identify a modified or redistributed product as an official MarkNest release.

You may truthfully describe a project as "based on MarkNest" or link to the original project. If you distribute a modified version, use a different product name and replace the MarkNest logo and extension icons so users are not led to believe that it is an official release.

Unmodified copies may retain the name and logo when they are clearly identified as copies of the official MarkNest project and preserve the original copyright and license notices.

For permission to use the MarkNest brand in another way, open an issue in this repository.
