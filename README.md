# MarkNest

MarkNest 是一款免费的浏览器收藏整理工具，帮助你快速查重、分类、移动、删除和导出收藏，并检查长期未用与失效链接。

## 主要功能

- 按文件夹查看和搜索 Chrome 收藏
- 快速查找重复网址与长期未用的收藏
- 批量移动、删除与撤销操作
- 调整文件夹结构并导出标准书签 HTML
- 导入其他浏览器导出的书签 HTML，与当前 Chrome 收藏进行本地比对
- 在用户主动授权后检查收藏链接是否可访问

## 隐私

MarkNest 不包含账号、广告、分析 SDK 或 AI 服务。收藏整理与书签文件比对均在本地完成。

[查看隐私政策](https://tinxixii.github.io/MarkNest/privacy/)
